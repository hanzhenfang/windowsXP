# Windows XP 桌面壳层功能补全设计

## 意图

把当前具有 XP 外观但多处只有视觉入口的桌面壳层，补成可连贯操作的本地演示。保留现有 Vue、Pinia、路由和素材，不改变产品为真实操作系统或带服务端认证的应用。

## 目标

- 补完整开始菜单、注销/锁定/关机/重启/待机的浏览器内模拟流程。
- 让桌面右键菜单、快捷方式属性和窗口工具栏菜单有明确且可用的行为。
- 让“我的电脑、回收站、网络邻居、Internet Explorer、个人博客”分别呈现有区分的可交互内容。
- 支持桌面窗口移动、调整大小、层级、最大化、最小化和关闭。
- 保存用户桌面设置与窗口状态；增加常用键盘快捷键和可见焦点。
- 桌面、电源菜单、对话框与窗口在 PC 和移动端均可使用。

## 非目标

- 不尝试关闭、重启或待机真实计算机。
- 不引入服务端、真实用户账号或密码认证；本地演示登录仅检查密码非空。
- 不访问用户本机磁盘，不提供真实网络文件共享，不克隆可运行的 IE 浏览器引擎。
- 不清除用户已有站点存储或扩大外部链接权限。

## 已确认的问题

开始菜单的“关闭”只关闭菜单；关机组件没有接入桌面且选项点击会打开个人博客；“所有程序”、桌面右键菜单大部分项目、窗口工具栏和属性窗口均为占位；IE 与个人博客指向同一外链；窗口状态刷新后丢失，窗口不支持调整大小。

## 实现方案

选择保留现有组件与 Store 的分阶段补全。整体重写会扩大回归面，也会丢弃当前可用的图标、窗口和移动端适配。执行顺序为：

1. 开始菜单和电源模拟：开始菜单列出应用、提供注销/锁定/关闭计算机；电源对话框提供待机、关闭、重启、取消。重启走现有启动页，注销/锁定回到登录页；关机显示模拟关机屏和重新启动入口；待机显示唤醒层。
2. 桌面操作：实现图标选择/排列/刷新、新建快捷方式、复制/粘贴快捷方式；属性支持重命名并持久保存；窗口菜单提供关闭/最小化/最大化等上下文相关命令。
3. 应用与窗口：我的电脑提供模拟磁盘和位置导航；回收站有可恢复/可清空的演示项目；网络邻居清楚标注模拟状态；IE 展示可输入网址的简易启动器并明确外链会新开标签；个人博客提供外链卡片。窗口可拖动、调整大小、置顶、最大化、最小化和关闭，移动端仍单窗口呈现。
4. 保存和键盘：将图标布局、标题、窗口状态及开始菜单偏好存入 localStorage；支持 Win 打开开始菜单、Esc 关闭菜单/对话框、Alt+Tab 切换窗口、Enter 激活选中桌面图标及清晰焦点样式。

## 产品行为选择

- 浏览器演示不可执行真实电源动作；相关入口必须明示为模拟体验，并始终给出可继续使用的恢复路径。
- 锁定和注销返回登录页；登录表单要求非空密码，但不声称验证身份。
- 外链使用用户点击后新开标签，并显示目的站点；不把第三方页面嵌入应用窗口以避免站点拒绝嵌入造成空白。
- 回收站使用应用内示例数据，清空/还原仅影响该示例数据。
- localStorage 解析或迁移失败时回退到默认桌面，不阻止启动。
