# Windows XP 密码登录页设计

## 意图

让登录页回到 Windows XP 欢迎屏的视觉秩序，解决 logo、头像区和独立入口按钮显得失衡的问题。PC 登录区使用头像、账户名、密码框和登录按钮；输入密码后按回车或点击登录进入桌面。

## 目标与边界

- 重整 PC 左右分栏，使 Windows XP 标识留在左侧，账户登录控件集中在右侧。
- 账户名使用“韩振方”，密码输入框采用 XP 欢迎屏常见的简洁样式。
- 删除头像拖拽解锁和单独的“进入桌面”按钮。
- 保留现有移动端选账户登录方式、启动展示、关机/返回交互、桌面路由及统一登录状态处理。

## 方案

采用 XP 风格登录控件直接替换 PC 拖拽滑轨。保留滑轨只替换提示和附加按钮会继续挤占登录区；重做整个站点不符合本次页面改造范围。用户已确认采用经典 XP 登录布局。

## 实现约束

- 复用现有 `enterDesktop` 流程，避免新增第二套导航状态。
- 密码字段可键盘操作并提供关联标签；密码按回车与按钮提交行为一致。
- PC 登录区在窄屏下仍可收缩，不影响移动端组件。
